# 暗黑系动漫混剪

把歌词、人物动作与画面空间组织在一起：短句传达语意，大词承担重音，人物遮挡建立纵深，动作和短效果制造冲击，静段与画幅收放控制强弱。本 skill 提炼自 V1–V3；案例数字是经验依据，不是新作品的配额。

## 从任务进入

先确认现有材料中的音乐、素材、参考分析、期望时长与交付目录。沿用用户已指定的范围和授权；已有版本需要保留时，在独立版本目录制作，源文件保持只读。密码或路径已在上下文给出时直接使用。缺信息但可独立推进时，先做素材探查与参考拆解。

按当前工作阅读：

- 分析参考、规划故事和卡点、插入或增加歌词：[音乐、叙事与空间歌词](references/music-lyrics-story.md)。
- 挑镜头、加全彩漫画、调色、抠像、裁切、滤镜与转场：[视觉设计](references/visual-editing.md)。
- 搭建时间线、渲染、换素材或交付：[制作流程与质检](references/pipeline-and-quality.md)。
- 用随附工具或与自建渲染器对接：[时间数据与工具](references/timeline-and-tools.md)。

## 工作流程

1. **拆出参考的分工。** 记录故事段落、音乐能量起落、字的位置与遮挡、动作峰值、色彩关系和画幅变化。区分原动画固有效果、可见的后期现象与推测；不要把参考片的时间点或 BPM 直接套到另一首歌。
2. **建立素材证据。** 探测视频规格、字幕与色彩空间；先总览、再密集抽帧，记录有效源区间、动作峰、视线方向、主体位置和文字留白。用真实原彩漫画画格，保留页码和裁切记录。压缩包先验证解压结果，再用镜头级匹配替换旧来源。
3. **先做节奏与故事骨架。** 依音乐段落安排“建立—施压—冲突—停顿—再释放”的情绪进程，具体故事服从素材。动作保留准备、接触、反应；通过手、眼、门、武器或运动方向建立跨场景连接。留出能量低谷，先审无花效粗剪。
4. **让字属于镜头。** 歌词来自用户素材或提供文本，并保留识别不确定性。用词界控制显示范围，用附近实测重音控制落定、缩放或强调。按主体、视线与空间留白逐镜布局；跨切点可拆构图区间，保持语句身份。文字可以少而大、竖排、透视或成为视频窗口，但要能读。
5. **分层处理风格。** 曝光与黑位 → 冷暖关系 → 红色强调 → 漫画/人物/文字空间关系 → 短时滤镜和几何效果。动态画幅作用于背景时，可让真实前景轮廓突破黑边。画面与蒙版共享源帧、变速、裁切和相机矩阵。
6. **用峰值卡点。** 对齐动作接触、几何合拢、文字落定或闪帧峰值，不只是效果开始时间。硬切保持主体节奏；转场有明确的方向、构图或段落作用。单一重音先确立一个视觉中心，再决定是否叠加其它效果。
7. **从实际输出复核。** 先出代表样片，再分镜渲染；缓存必须依赖当前参数、素材、文字、转场前驱和代码。抽看首/中/末、最短歌词、蒙版边缘及效果逐帧，并验证最终成片完整解码、帧数、时间戳、音乐同步和峰值。数值正确不等于画面好看。

## 修订时保留的约束

- “更多素材/歌词/效果”要落实为新内容与新的构图作用；不要用数量掩盖遮脸、漏词、读不清、源区间无意重复或全片强度相同。
- 替换源镜头后重新检查人物位置、文字留白、漫画占位、字幕裁切、动作峰和蒙版配准；旧构图参数不能直接视为有效。
- 用整数输出帧表达切点。源秒数、镜头内帧位、全曲绝对帧位必须分别标明。30fps 的一个输出帧约为 33.3ms，不承诺未经验证的毫秒级同步。
- 技术证据来自哪次时间线和缓存要可追溯。区分自动检测、抽帧视觉检查与连续人工视听，不把其中一种描述成另一种。

## 交付

按任务提供成片、试听预览、源区间与效果参数、歌词/鼓点依据、蒙版与漫画配方、可复现命令和质检记录。若导出的是已合成镜头 XML，明确它只可重排，不是原生逐层 AE/PR 工程。

随附工具只负责时间结构检查和成片抽帧；根据目标环境选择剪辑软件或实现渲染器，不把此 skill 描述为附带全部素材的一键复刻工程。
