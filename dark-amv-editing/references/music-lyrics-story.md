# 音乐、故事与空间歌词

用于设计以音乐和人物情绪驱动的动漫混剪：先安排全曲强弱、动作因果和歌词语气，再按镜头中的人物、留白与建筑线条排字。本文提炼自 ref3 成片分析与 V1–V3 工程；数值案例以 V3 最终时间线及其质检记录为准。案例中的歌曲、人物、时长、字体尺寸与阈值均可替换。

查阅顺序：音乐定位见第 1–2 节；故事与素材组织见第 3 节；歌词时序、排版与遮挡见第 4–6 节；实际渲染验证见第 7 节。

## 1. 将音乐的三套时间分别保存

| 时间层 | 用途 | 不宜混淆的内容 |
|---|---|---|
| 人声词界 | 句子开始、结束、短句交接 | ASR 时间有误差，不能因为附近有鼓声就平移整句 |
| 拍格与实测瞬态 | 段落周期、切点候选、动作/文字落定 | 拍格是音乐结构模型；检测到的瞬态是音频证据，两者不必重合 |
| 输出帧号 | 可实际渲染的切点与动画节点 | 视频帧量化误差不等于音频检测误差 |

从实际解码音频建立统一时间原点，记录采样率、样本数和解码时长。使用容器时间戳的分析还应说明音频起始偏移；不要把另一份参考视频的偏移量套到当前歌曲。

先绘制全曲波形、分段能量与起音分布，再标注主歌、反复段、间奏、能量回落与尾声。段落标签可以是编辑功能名称，不必冒充已经确认的正式曲式。音乐较安静时，检查它是仍有人声、纯器乐、余响还是接近静音；这些情况需要不同的画面停留。

拍速估计宜跨多个区间核验。自动追拍在稀疏伴奏处漂移时，保留可靠的稳定拍格作为参照，同时保留偏离拍格的真实起音，不要把漂移的检测点直接当作歌曲突然变速。

**V3 案例参数：** 解码音乐为 173.539048 秒；编辑拍格为 94 BPM，相位 0.03396 秒，一拍约 0.638298 秒。原分析在约 139–149 秒出现自动追拍偏移，因此编辑沿用经过全曲拟合的稳定网格。最终 30 fps 时间线为 5207 帧、173.566667 秒，保留整首歌曲；多出的约 27.6 ms 是画面帧数向上取整，不是额外剪接的音乐。

## 2. 检测实测瞬态，再决定谁承担重音

需要自动辅助时，可分频带计算正向频谱通量与短时能量上升，抑制持续音的影响；按局部底噪、峰值突出度筛选，再合并跨频带的同一次起音。保留原始检测时刻，另外计算它到拍格的距离。

V3 可复查的检测配置如下，属于该首歌的实现案例：

| 项目 | 案例值 |
|---|---|
| 分析采样率 | 22050 Hz 单声道，交付仍使用原曲音轨 |
| STFT 窗与步长 | 1024 样本，110 样本步长；约 46 ms 窗、5 ms 步长 |
| 频带 | 30–170 Hz、170–2400 Hz、2400–9500 Hz |
| 起音评分 | 65% 正向对数频谱通量 + 35% 短时 RMS 上升 |
| 时刻细化 | 在谱峰前 35 ms 至后 12 ms 内查找频带能量上升峰 |
| 跨频带合并 | 约 40 ms 窗口 |
| 结果 | 1058 个合并瞬态；287 个较强、接近拍格的强调候选 |

这里的低频候选可能来自合成贝斯，中高频候选可能来自人声辅音、呼吸或效果声。`confidence` 是工程评分，并非经过校准的乐器分类概率；未分轨或听辨确认时，使用“低频起音候选”“广谱瞬态”等名称。V3 标注的约 22–28 ms 检测不确定度也不应包装成绝对精度。

为一个音乐节点选择明确的视觉承担者：

- 段落转折：切换人物关系、镜头密度、色彩或画幅。
- 乐句重音：让短句、关键词或构图落定。
- 动作重音：让接触、发力、转向、关键姿态对齐。
- 镜内重音：保留同一镜头，以短效果峰值或轻微镜头脉冲响应。

同一拍不必同时承担切镜、巨字、闪光和变速。优先选择对故事最有作用的一项，其他项降低幅度。效果有准备过程时，把**峰值或落定帧**对齐声音，而非只吸附效果第一帧。

切点选择也要区分用途。V3 的镜内脉冲主要使用 287 个强调候选；最终切点另优先保留原位附近可靠的低频/广谱起音，再搜索更强的候选。这两份集合不是同义词。该工程的动作段允许切点移动最多 ±11 帧、主歌约 ±2 帧、相邻镜头至少 8 帧；116.8–147 秒退潮段不重排切点。这些限制用于保护本片语意和呼吸，换曲时应重新决定。

对动作卡点，先在源素材中标记准备、发力、接触、反应，再把关键源时刻映射到输出节点。可用归一化分段时间曲线记录：`[[0,0],[输出进度,源进度],[1,1]]`。保持映射单调，并检查关键姿态前后是否仍有足够动作信息。V3 有 28 个经素材检查的动作节点另外对齐；不能据此声称全片每个动作都经过逐帧重定时。

## 3. 用音乐结构组织故事，而非只按角色轮番展示

先写一句贯穿全片的冲突，再将它分配到音乐段落。每段记录：人物当前状态、想接近或逃离的对象、段末发生的变化、需要的镜头功能。优先寻找能表现这些变化的动作和反应，随后挑技术上适合裁切、排字和分层的窗口。

V2 的主题线是控制、反抗、接近、背叛、关系停顿、再次发动；V3 在这条情绪线上增加暗黑意象，保留了中后段的回落。以下是 V3 最终画面章节的简化分组，边界不等同于原始音频分段草稿：

| 输出区间（秒，约值） | 叙事功能 | 画面与歌词的取舍 |
|---|---|---|
| 0–24.93 | 冷开场、身份与控制 | 门、凝视、手势与反应；先建立人物关系与视觉母题 |
| 24.93–50.43 | 拒绝与压迫、反击准备 | 人声承载语意；保留目光、停顿与动作准备 |
| 50.43–71.17 | 第一轮动作 | 对手、发动、交锋、起身形成局部因果链 |
| 71.17–96.40 | 接近与危险、假面松动 | 关系镜头与威胁意象平行；让分句推进故事 |
| 96.40–116.83 | 背叛与追逐 | 更密的动作和关键姿态，短效果强调接触 |
| 116.83–146.83 | 道歉、失去与蓄力 | 降低运动和文字强度；无歌词的间奏留白 |
| 146.83–166.97 | 最终释放 | 召回前文动作和意象，升级重音而非随机换一批素材 |
| 166.97–173.57 | 尾声 | 顺着音乐余响收束动作与关系，不截掉衰减尾部 |

跨场景用可见的相似关系连接：眼睛承接凝视，手形连接接近与控制，启动动作引出爆发，门和走廊建立受限空间，重复的中轴构图承接心理意象。它们可以建立主观联系，不应被文案误述成原作中真实连续的事件。

局部动作组尽量保留“准备—接触—反应”，跨场景则使用视线方向、运动方向、手形或构图轴线帮助观众定位。找不到可靠的动作衔接时，可以插入反应镜头或意象，不要靠复杂转场掩盖所有因果缺口。

退潮不只等于延长镜头。减少同屏信息、压低运动幅度、减少歌词强调和特效频率，同样能形成停顿。V3 116.83–134.07 秒为 7 镜；后面的间奏仍有构图变化，但不需要继续填字。ref3 中能量回落后的眼睛、触碰和对称意象也支持这种“停留—蓄力—再释放”的组织方式。

## 4. 保留歌词依据，将人声时间与显示动画分开

从用户提供的本地音频转写，保存词级时间和原始识别结果。遇到歌唱、气声、快速连读时，可对照两份独立模型结果，再对疑难区间带上下文重识别。相同模型的局部复识别是补充证据，不是第三个独立模型。

自动结果一致仍不能代替听辨。省略不能可靠确认的词，保留可确认片段；标题或上下文辅助规范化应单独记录依据。不得用排版完整性为理由补出没有证据的连接词，也不要把尚未听校的结果称为准确全文字幕。

最小数据应能追溯这些字段：

| 数据层 | 建议保留 |
|---|---|
| 原始识别 | 模型、原词、词起止、概率或评分、时间不确定度 |
| 源短句 | `id`、`text`、`start/end`、`words`、`confidence`、`evidence`、规范化说明 |
| 音乐落点 | 瞬态 ID、实测时间、目标帧号、相对人声偏移、类型候选 |
| 显示段 | `phrase_id`、`shot_id`、显示起止、原人声起止、布局、入场时长、脉冲帧 |

V3 从 V2 的 41 个精选短句、109 个显示词，扩充至 89 个源短句、260 个词；这些短句经过语意拆分得到 101 个显示词组，再按跨镜头构图展开为 171 个显示段。**源短句数、语意词组数与构图区间数应分别统计**，避免把拆布局当成新增歌词。

逐句决定哪些词需要成为事件。重复唱出的词可分次出现；较长句可按自然语义拆成两组；普通连接词可随短句一起显示。若要让每个词独立揭示，应保存并消费词级动画状态；仅给整块文字做缩放脉冲不能称为逐词动画。

一个可复用的入字流程：

1. 以确认的人声起点 `v` 为基准，在允许窗口内寻找有依据的实测瞬态 `t`。
2. 找到时，令关键词揭示、缩放峰值或文字落定对应 `t`；必要时提前少量帧开始动画。找不到时保留人声起点，不虚构鼓点。
3. 用 `f = round(t × fps)` 保存实际输出帧，同时保存 `f/fps − t`，让帧量化可审查。
4. 原人声起止单独保留；只调整显示层的提前进入、交接和短暂阅读延续。避免两条不同短句相互覆盖。

**V3 案例限值：** 源词强调点与人声起点的偏差目标不超过 0.12 秒，显示提前也不超过 0.12 秒。实际构建器通常以约 2 帧预备动画、最多 0.10 秒提前来安排词组进入；无落点时采用短入场。原始分析有 129 个词级落点，最终布局保留 122 个歌词脉冲引用，二者不能直接当成同一计数。

例如案例的一个人声词起点为 5.220 s，所选瞬态为 5.256100 s，相差 36.1 ms；30 fps 输出落在第 158 帧，即 5.266667 s。这里约 10.6 ms 是帧量化误差，还要另看 ASR 与瞬态检测的不确定度。

跨镜头仍在唱同一短句时，保留 `phrase_id` 和原词界，按下一镜构图改变排版。很短的续段应快速呈现，不必重新播放完整飞入。V3 对不足 0.24 秒且已经在前镜出现的续段，将入场缩到 1 帧、关闭额外滑移；14 个 4–6 帧布局段是同句续段，不能按孤立字幕的阅读时长直接判错。相反，一条独立的新句若只有数帧，就需重新检查切点、显示范围或选词。

## 5. 每个布局回答“为什么放在这里”

从实际裁切、变速后的首、中、末画面寻找可用空间；不要仅按镜头序号轮换左、右、上、下。为每镜记录人物焦点、脸/眼/手/武器范围、建筑线条、可读留白，以及一句 `layout_basis`。替换素材后重新判断这些字段，沿用旧坐标很容易把文字压到新主体上。

优先级通常是：关键表情和动作可见，其次句子可读，再考虑排版装饰。文字可以贴近人物轮廓、承接视线方向、顺着衣领或墙边走，也可以占用经过设计的画幅黑区；决定取决于当前构图。

| 画面条件 | 可用文字形态 | 检查重点 |
|---|---|---|
| 主体一侧有暗墙、天空或水面 | 短句、两行块 | 对比、视线指向、入场是否越界 |
| 门柱或狭长边框 | 竖向文字、短词 | 旋转后的真实高度；不要只检横向宽度 |
| 地面、屋顶、桌面、砖墙 | 透视文字 | 四角顺序与凸性、远端字高、镜头运动中的附着 |
| 大轮廓前有动作、后有空间 | 巨型后置关键词 | 被挡的是装饰部分还是辨词关键部分 |
| 简洁重音节点 | 字形视频窗口 | 字内动态是否可辨、字外覆盖是否过强 |
| 情绪回落 | 较小、较稳的短句 | 仍能读到；安静不等于低对比到消失 |

`pos`、`quad`、`max_width`、`max_height` 可用输出画布归一化坐标；字体大小仍需结合最终输出像素检查。长句挤进窄 `max_width` 时，渲染器会把整行缩小，单独提高字号未必有效：先按语意换行或换位置，再调整字重、行距和宽度。

V3 的主文字用粗体大写、暖白和局部红色，安静段改用较小衬线字。普通词组案例字号约 126–150 px，少量单词与后置大字更大；退潮段约 67–86 px。它们基于 1920×1080，经过 `max_width` 和透视变换后的真实字高才决定可读性。普通文字的鼓点缩放幅度约 2.6%，安静段约 1%；这些是层级示例，不是跨项目的固定规范。

透视排字先对齐能看见的平面线条。画面只有轻微推拉时，可让文字共享镜头矩阵；复杂运动再考虑平面跟踪。仅有二维单应变换的实现，不应宣称已经完成三维相机解算。

## 6. 用分层遮挡保住人物，也保住词语

人物遮字的基本次序是：完整背景 → 后置歌词 → 同镜头前景人物/手/武器 → 必要的前置歌词。将背景窗口和人物轮廓分开裁切，可让手、头发或刀刃突破画框。文字 Alpha 挖空、矩形/斜向窗口、真实人物轮廓是不同资产，不要混称为人物抠像。

前景和背景来自同一段源视频时，共享源帧索引、变速曲线、裁切和相机矩阵；输出帧与 alpha 一一对应。只处理真正发生文字交叠的轮廓与时间范围通常更有效，前提是边缘与运动连续。

后置文字仍要有可读窗口。人物遮住中间字、脸部前景覆盖大半句时，先将文字移到另一侧、拆行或减少遮挡面积；必要时改为前置。不要因已经有蒙版就强行让所有句子后置。

V3 的实际修订包括：CT17 将两组短词分别放到左下与左上，取消过度遮挡；CT37 将两组词分别放到右下和左下；CP01 将短句改为前置；CT53 把文字移离白衬衣。它们说明后置大字是可选表达，人物和词语可读性才是判断依据。

最后确认效果处理次序。V3 的动态几何与部分滤镜在文字合成后执行，因此会改变整幅画面中的文字；局部细节窗也可能把已有字形一起复制。静态文字边界检查无法证明最终成片可读。案例曾取消 MV60 的细节窗，避免复制出孤立字母；这类问题应在实际合成帧中识别。

## 7. 将“数据正确”与“实际可读”分开验证

先完成能阻止错误扩散的数值检查，再审查已渲染画面。以下检查对应不同结论，不能互相替代。

**数值与依据**

- 每个源短句、每个采用的词都有布局引用；区分未采用的不确定词与意外漏词。
- 显示段在所属镜头内，原人声尾界元数据正确；不同短句无意外交叠。
- 入场落点及脉冲引用实际存在的音频事件。歌词帧号可用全片绝对帧；镜头内部脉冲若用局部帧，要先加镜头起点再比较。
- 在入场、稳定期和退场检查实际文字 Alpha 边界，包含旋转、透视、跟随与脉冲缩放；四角在画布内仍不代表透视后的字高足够。
- 检查帧量化、ASR 与检测误差，单独报告。轻微偏差先看是否有声学与画面依据，再决定是否调整。

**真实渲染画面**

- 只从与当前时间线、源资产和渲染代码签名一致的缓存解码抽帧。转场引用前镜出场画面时，前镜歌词、蒙版变化也应使相关转场缓存失效。
- 每个歌词构图区间至少查看实际中点，结合首/末或入场阶段；对人物遮字、短闪、镜内几何和短续段补查多个时刻。
- 缩小到常见观看窗口检查脸、手、武器和文字，再看输出分辨率下的轮廓细节。联系表用于覆盖全片，疑难处要打开单帧或短片段。
- 单帧被短效果改变不等于整句不可读；单帧偶然读清也不能证明整段合格。看可读窗口是否足够、关键词是否恢复完整、是否挡住动作重心。
- 正常播放检验句子阅读、声画重音与段落落差；不能以技术解码或联系表代替连续听看，并在交付中如实说明实际检查范围。

**V3 的已验证结果及边界：** 145 镜、171 个歌词构图区间的当前缓存与帧数一致；89 个源短句、260 个词均进入布局。92 个记录切点对照实测瞬态后，帧量化偏差中位 9.161 ms、最大 16.599 ms，均不超过 30 fps 半帧；122 个歌词脉冲和 287 个镜头脉冲有实测依据。这些数字证明引用与量化一致，不能证明鼓的乐器身份或所有观众的感知同步。

视觉复核还保留了非阻断事项：两处词首因镜头边界显示晚约 0.133/0.127 秒，略超 0.12 秒设计目标、超出量均不足半帧；未伪写成零偏差。某后置句在运动中逐渐露出，复核后续帧才确认完整；某暗红文字帧来自 5 帧滤镜，后续白字恢复。这些案例支持对完整动画区间判断，而不是只盯一张缩略图。

本次便携审查还发现一个跨镜续段的动画落定晚于本段结束 1 帧，以及 8 个歌词脉冲帧恰在显示结束端点（部分时间字段有约 0.0000003 秒舍入差）。审查器将边界 1 帧以内的脉冲引用列为警告，不当作该段已显示的峰值；更远的时序错配仍报错。应与后继构图联合审查，不能仅验证 `start + enter_duration` 等于落定时间就宣布入场有效。最终便携结构审查为 0 错误、9 警告，原工程数据保留。
