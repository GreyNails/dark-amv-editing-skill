# 视觉剪辑：取景、色彩、构图与遮挡

这份参考提炼自参考片分析及 V1–V3 的实现和返修。参数是可调整的起点，不是每个镜头必须执行的清单。先确定镜头的叙事作用和主要视觉信息，再选择能强化它的处理。参考片中可见的效果与推测的实现方法要分开记录；原动画已有的烟尘、残影、镜像或摄影运动，不应一概归因于后期剪辑。

按需阅读：[镜头与坐标](#镜头与坐标)、[取景与动态画幅](#取景与动态画幅)、[调色与颜色蒙版](#调色与颜色蒙版)、[漫画和几何构图](#漫画和几何构图)、[人物蒙版与层序](#人物蒙版与层序)、[转场和短效果](#转场和短效果)、[视觉复核](#视觉复核)。音乐、文字语意与故事分段见 [music-lyrics-story.md](music-lyrics-story.md)；工程缓存和完整交付检查见 [pipeline-and-quality.md](pipeline-and-quality.md)。

## 镜头与坐标

### 选的是连续窗口，不是一张漂亮截图

粗联系表用于发现场景，候选窗口用于确认动作。对候选保存源首帧、中帧、末帧，以及应用裁切和适配后的同组三帧；原动画切点、动作接触和快速闪帧附近再加密检查。记录“已看三帧”“已逐帧查切点”等真实验证范围，不把一个中点写成整窗验证。

暗黑段落优先寻找实际内容：压迫的空间、控制的手势、受创后的停顿、冷漠凝视、危险逐渐显露。调暗一段明亮日常不会自动产生同样的叙事作用。动作段可组合“准备—接触—反应”，关系段可用手、眼、门、背影等意象建立联系；保留较安静的镜头，才能让下一次冲击有落差。

源清单记录相对路径、时长、尺寸、帧率、色彩标记及字幕类型。镜头 ID 保持稳定，与输出序号分离。下面是字段示意，不代表所有渲染器都直接支持这些字段：

```json
{
  "id": "hallway_threat",
  "source_id": "feature_sdr",
  "source_in": 120.2,
  "source_span": 1.7,
  "fit": "contain",
  "crop_native": null,
  "description": "远处人物被门框围住，近处黑影遮住半边走廊",
  "tags": ["threat", "control"],
  "focal_center": [0.57, 0.46],
  "subject_bbox": [0.50, 0.28, 0.14, 0.36],
  "text_zone": {"bbox": [0.10, 0.38, 0.28, 0.24]},
  "coordinate_space": "normalized_output_after_crop_and_fit",
  "action_peak_source_offset": null,
  "no_internal_cut": true,
  "subtitle_status": "首中末与边界加密取样未见硬字幕",
  "review_status": "verified"
}
```

- `crop_native=[x,y,w,h]`：源像素坐标，先裁切，再适配输出画布。
- `focal_center=[x,y]` 与 `subject_bbox=[x,y,w,h]`：明确区分中心和包围盒。V3 电影索引曾用四元素主体框，TV 索引用两元素中心，混用会使取景偏移。
- `text_zone`、透视 `quad`、漫画窗口：建议统一到裁切与适配后的输出画布，归一化至 0–1。保留坐标空间说明，不能把源截图坐标直接当作成片坐标。
- 动作峰只填写亲眼确认的位置；它可以是源绝对秒或窗口内偏移，但字段名称和转换要明确。没有明显峰值时允许为空。

### 去重与版本配准

同一源的两个半开区间在 `max(in_a,in_b) < min(out_a,out_b)` 时有时间重叠。还要检查同场景在总集篇、单集、另一封装中的重复；不同文件名不代表不同画面。刻意回忆可以重复，记录它的叙事目的，避免误把候选堆叠成重复动作。

更换总集篇、电影版本或清晰度时，用连续姿态进行视觉配准。片头、删节和帧率差异会使全片偏移不恒定。已配准的一个镜头不能证明其它镜头共用同一时间差；人物蒙版尤其需要逐帧对应。

## 取景与动态画幅

### 先保主体，再决定填满程度

`contain` 保留整个裁后画面并补边；`cover` 等比放大到填满输出，再裁去溢出部分。禁止用横纵独立缩放填满画布，以免脸、手、武器变形。宽银幕且人物分居两端时，优先试 `contain`；竖向主体或中央近景可以试 `cover`，但要检查完整运动范围。

硬字幕按镜头处理：先观察整个窗口的字区，再试裁底、重构图或换无字窗口。某个源曾使用 `[0,0,3456,1260]` 的裁切去除字幕，这是该源的像素例子，不是所有片源固定裁掉相同比例的依据。字幕进入脸部或有效画面时，换窗口通常比强裁更稳妥。软字幕应控制流映射，避免额外烧录。

检查原始画面与成片的差异：原动画本身出框的头部、机头或手，不等于新剪辑裁坏；反之，源里完整的脸被漫画窗口或新黑边切掉，需要改构图。变焦、倾斜和运动模糊之后也应再核对边缘。

### 黑边是一层可动遮罩

固定输出画布，改变背景可见窗口；不必改变容器分辨率。`b` 表示顶部和底部各占画布高度的比例，仅考虑这层遮罩时可见比例为 `W / (H × (1−2b))`。已经含原生黑边的宽银幕素材应直接看适配结果，不能把原生黑边与新增黑边简单相加。

以下采用镜头归一化时间 `u`，关键帧为 `[u,b]`：

```json
{
  "opening": [[0, 0.49], [0.32, 0.08], [1, 0.08]],
  "impact": [[0, 0.075], [0.28, 0.19], [0.40, 0.065], [1, 0.065]],
  "closing": [[0, 0.18], [0.55, 0.18], [0.90, 0.49], [1, 0.50]]
}
```

这些例子分别形成窄缝展开、短暂挤压后释放、闭合。关键帧应随本镜动作与音乐调整。V3 普通 TV 镜头常见 `b=0.075–0.15`，极窄桥段可更大；已是宽银幕的电影常仅使用 `0.035` 的额外遮罩参数。不能仅为统一数值而再裁去电影人物。

轻推近可以从 `1.00→1.015–1.025` 试起，重音脉冲也应短而可恢复。源画面与人物蒙版必须应用同一空间变换。若希望人物突破黑边，将背景黑边放在人物前景层之下；全画面末端再加黑边会把突破效果重新裁掉。

## 调色与颜色蒙版

### 三层处理，分别控制强度

1. **基础匹配**：统一输出色彩流程，修正不同源的曝光、黑位、饱和度差异。HDR 输入先做合适的色调映射或选已验证的 SDR 源；改色彩标签不等于完成转换。
2. **场景情绪**：灰蓝环境与较暖肤色、火光与冷夜、钢铁与血色各保留相互区别。用眼睛、白衬衫、刀刃或背光作为亮度锚点，暗部仍应看得见关键轮廓。
3. **短冲击色**：红色选区、伪色、反相线稿等只在需要的动作或重音附近出现。效果退去后返回可读的基础画面。

V3 自定义 8-bit RGB 流程的实例参数如下。`contrast` 是绕自定义中点的倍率，`saturation` 是相对亮度的插值倍率，增益是 RGB 顺序；它们不等同于剪辑软件里同名滑杆的刻度。

| 倾向 | contrast | saturation | RGB gains | 适合起点 |
|---|---:|---:|---|---|
| 冷夜 | 1.045 | 0.90 | `[0.965,1.005,1.07]` | 夜景和低光人物，避免继续压死黑位 |
| 冷钢 | 1.14 | 0.76 | `[0.955,1.005,1.09]` | 金属、都市和动作背景 |
| 暖光 | 1.09 | 0.94 | `[1.055,1.01,0.94]` | 火光、夕照及与冷段落形成色温落差 |
| 血色强调 | 1.14 | 1.04 | `[1.06,0.945,0.97]` | 已有红色元素的短动作镜头 |

实例曲线曾将输入 `[0,16,40,90,150,210,255]` 映射为 `[1,10,32,83,151,215,250]`，再叠加对比与色温；不要在本来低曝光的片源上盲目复刻全部压暗步骤。轻暗角约 `0.06–0.13` 可收束视线；柔光只用于有亮部依据的镜头，否则容易把黑色线条和脸冲淡。

### 颜色选择与人物遮罩不是一回事

| 手法 | 作用 | 注意点 |
|---|---|---|
| 保留红色、其余冷灰 | 让血、眼、服饰或标题成为视觉锚点 | 检查肤色和暖光误选；选区需要羽化 |
| 主体保色、背景冷灰 | 建立人物与环境的前后关系 | 需要真实主体 alpha，不能用颜色阈值假装轮廓 |
| 斜向色带扫描 | 让恢复原色或伪色沿动作方向通过 | 用带宽、边缘羽化和时间包络控制，不把整个脸长时间分割 |
| 双色分区、圆形显色 | 强调冲突或视线焦点 | 分区几何与画面重心一致，文字不要恰好压在明暗接缝 |

一个保红选区实例使用 OpenCV HSV 的 `H<13 或 H>169`、`S>72`、`V>38`，其中 H 的范围是 0–179，S/V 是 0–255。阈值依赖源色彩；换环境应重新取样。V3 斜向扫描的归一化带宽曾取 `0.16`，边缘羽化约 `0.035`。这类参数需结合画布尺寸与速度审片。

检查实现是否实际使用了标注的强度参数：V3 的部分专用颜色分支直接计算选区混合，并不读取通用 `opacity`。迁移配方时以代码和输出为准，不能只修改一个不起作用的字段。

## 漫画和几何构图

### 保留漫画原彩色，给每层分工

漫画可承担反应、回忆、姿态呼应或构图延伸，不必每次出现都解释剧情。先选主视觉，再确定漫画、动画和文字各占何处；优先匹配眼神、手势、武器走向或明暗轮廓。

V3 保留原彩色插图，再轻度降饱和和压亮度，使其与视频相融；示例饱和倍率约 `0.88`。这不同于整张覆盖红色。允许不同漫画保留各自的红、蓝、暖黄等色块，让红色冲击仍有对比。

| 构图 | 适合的条件 | 常见失败 |
|---|---|---|
| 三联画 | 三个姿态或视线有关系，单格主体足够大 | 每格都塞长句，信息同时竞争 |
| 斜分屏 | 边缘区域有负空间，斜线顺动作 | 斜边切眼、切手或切电锯尖端 |
| 两侧漫画、中间动画 | 动画主体集中在中部 | 两个人分居左右，被中间窄窗全部裁掉 |
| 小窗插画 | 原片主体和空间需要完整保留 | 窗口挡住脸、歌词或动作接触点 |
| 漫画人物剪影前景 | 需要前后层次或回应画中人 | 静态人物挡住整句字，或被误称为视频人物抠像 |

V3 一个有效的窄竖窗使用 `manga_box=[0.035,0.22,0.23,0.59]`，即画布左侧约 23% 宽、59% 高；中央动作主体与右侧歌词仍可见。这是检查了具体画面的结果，不是通用安全区。

面板可以等比裁切和轻微漂移，但逐帧确认眼睛与武器是否仍在窗内。两侧人物的全景若与中央窄窗不兼容，扩大窗口、换侧边小窗或撤掉该镜漫画，比强行保留效果更合理。V2 就曾撤去挡住脸的右侧漫画，以及裁掉两端人物的双栏布局。

### 几何裁切合并要保留像素比例与时间关系

几何切片可以来自同一时刻的完整画面，让拼合落点恢复原构图；除非明确需要错时效果，不要让各片无意使用不同源时刻。

| 方式 | 实现思路 | 风险 |
|---|---|---|
| 竖条交错 | 三条等宽片交替上下位移后归位 | 归位前手脸暂时断裂，持续时间不宜抢走主体动作 |
| 上下铰合 | 上下两片反向横移后合拢 | 文字跨接缝时被分成两半 |
| 四角拼合 | 四个象限从相反方向汇合 | 小幅足够，位移过大会只剩黑底 |
| 斜缝展开 | 窄斜窗逐渐展开为全画面 | 短歌词在展开前已经结束 |
| 细节放大窗 | 从眼、手、器物取样再嵌入 | 若从已合成文字的画面取样，会复制残字 |

V3 拼合常用约 8–10 帧落定（30fps 下约 0.27–0.33 秒），只是实例。短镜头或短词可能需要更快落定，甚至跳过入场。重点在落点与鼓点、动作接触一致，以及落定后仍有阅读时间。

明确几何效果所处层级：对动画背景做切片，文字可以保持完整；对最终合成画面做切片，人物和文字都会被切开。两者都可用于创作，但不能让意外层序决定效果。细节窗优先从未叠字的画面取样；V3 曾因放大窗复制出孤立字母而撤销该效果。

## 人物蒙版与层序

### 三种遮罩分别命名

- **人物轮廓 alpha**：决定谁挡住字、谁能越过黑边。
- **几何窗口**：决定哪一块视频或漫画可见。
- **文字 alpha**：决定字形本身可见，或让视频从字形镂空处透出。

矩形、椭圆和人物包围盒都不能替代声称已经完成的人物轮廓抠像。文字镂空可用较高不透明度的色盖层减去字形 alpha，再露出底部原片；它也不是人物遮挡。

### 蒙版必须与源画面共享时空映射

蒙版配方至少保留 `source_id`、源入点与长度、`crop_native`、`fit`、输出帧数、变速映射及关键帧/轮廓来源。渲染时由同一个“输出帧 → 源帧”映射取视频与 alpha，再应用同一个取景、平移、缩放和旋转矩阵。源、裁切、速度或适配方式改变后，原蒙版不能直接视为仍有效。

V2 有两类可复用做法：

1. **边界清楚、运动较小的人像**：在 640×360 代理上手绘前景多边形，腐蚀得到确定前景，膨胀得到待分类边缘带，再逐帧细化；检查头发、衣领、肩和手。示例用了约 5×5/7×7 核及轻微 3×3 羽化，但须随分辨率和线条宽度调整。
2. **动作和细长武器**：手工关键帧之间，当前帧直接向两侧最近的关键帧求光流对应，避免递归传播不断累积漂移。两侧预测交集可减少背景拖影，细刀刃再用独立轮廓补回。检查首、中、末及姿态最大变化处。

这些是可选实现，并非要求固定分割算法。自动抠像或跟踪可用于初稿，最终以实际边缘为准。漫画静态剪影可以单独制作，但不能拿它证明动态视频人物已正确跟踪。

一个常见层序是：

```text
源视频与基础调色
  → 背景处理、漫画窗口与背景黑边
  → 人物后方文字
  → 与源同帧同变换的人物前景
  → 少量需要保持可读的前方文字
  → 明确设计的全局效果
```

人物前景不必挡住每个字。若眼睛、手或锯齿盖住关键词大半时间，可移动字、拆行、把一部分置于前景，或缩短遮挡阶段。判断的是整段阅读体验，不是某一帧所有字是否同时完整。

## 转场和短效果

### 先用画面关系决定切点

姿态、运动方向、形状、光线和手部遮挡可以自然连接镜头；清楚的动作接力本身已能形成冲击。需要效果时，沿既有方向增强，不要每个切点都加入不同花样。

转场两端先统一画布和颜色流程。前镜的退出状态包含它实际的文字、蒙版、漫画和调色；只取前镜裸视频可能让转场头部丢字、跳色或突然换构图。相关渲染依赖见 [pipeline-and-quality.md](pipeline-and-quality.md)。

以下是 1920×1080、30fps 案例中的起点，换分辨率和帧率时按视觉时长与相对位移换算：

| 效果 | 案例尺度 | 使用判断 |
|---|---|---|
| 分门、斜楔、条带拼合 | 约 5–7 帧 | 顺主体方向，不遮掉动作峰后的反应 |
| 鞭甩、短推近 | 约 3–4 帧 | 需要方向连贯或明显冲击时 |
| 溶解、虹膜 | 约 7 帧 | 适合心理或空间转换，不必套在每次鼓点 |
| RGB 偏移 | 约 9–12 像素、4–5 帧 | 接触瞬间使用，恢复后线条应重新对齐 |
| 推近脉冲 | 峰值约 4.5%–5.5% | 与动作接触同步，保留后续回落 |
| 浅闪光 | 原画与闪色混合约 0.16 | 不能长时间洗掉眼睛、字幕与动作细节 |
| 线稿、伪色、色阶压缩 | 约 5 帧 | 用作短标点，确认相邻帧能读懂原动作 |

效果应有入峰与回落。一个可用的短包络是 `max(0, 1−abs(frame−peak)/width)^2`；中心放在已确认的动作或音乐峰，而非一律放在镜头第一帧。闪色、抖动和 RGB 偏移可以共用包络，避免各自乱跳。安静段可只留轻推、色温和字的运动。

## 视觉复核

只检查与当前参数匹配的缓存。首、中、末之外，加看每个歌词事件中点、入场落定、退出、动作峰及强效果的前后帧。对很短的文字或切片入场，逐帧确认“出现—完整可读—消失”确实存在；再按正常速度检查段落节奏。

| 症状 | 优先查因 | V1–V3 的有效修法 |
|---|---|---|
| 字很高很瘦或远端极小 | 把长单行强塞进狭窄透视四边形 | 先拆成 2–3 行，再调字号、平面宽高与角度 |
| 脸或两人关系消失 | 中央窄窗、漫画侧栏、`cover` 或黑边 | 改为保全景的适配、缩窄漫画或撤去该层 |
| 文字被人物持续挡住 | 后方文字层级与主体轨迹冲突 | 改负空间、分层放字、让关键词在前景 |
| 白字与白衣/天空混在一起 | 局部对比不够，不能只看整图明暗 | 移位，适量描边/阴影，或换与场景协调的字色 |
| 放大窗出现半个字母 | 从已叠字的合成帧取样 | 改为从原视频取样，或取消该窗 |
| 镜尾残留旧歌词或条纹 | 可变帧复用了同一缓存图像内存 | 在叠层前复制缓存图，抽查实际输出的末尾数帧 |
| 蒙版拖尾或锯齿脱离 | 源时基、变速、空间矩阵不一致，或跟踪漂移 | 先查映射，再补关键帧和细线轮廓 |
| 看似死黑 | 暗源、压黑曲线、线稿冲击或故意闭合混淆 | 看前后帧并比较源，区分设计黑场与失误 |
| 只在开头缺字 | 文字已开始，但几何入场仍关闭 | 提前或加快展开、延后文字，或让文字独立于切片 |

暗黑不意味着所有暗帧都不合格。V3 中短线稿冲击和水下下坠末端的低亮度有明确上下文；同样，黑场检测不能替代对丢帧、错误遮罩或过强压黑的排查。记录已检查的帧与仍未覆盖的范围，不把抽帧复核等同于完整连续观影。

### 本参考的证据范围

方法来自参考片的可观察分析、V1 的电影镜头索引、V2 的漫画合成与蒙版配方，以及 V3 的暗黑素材索引、颜色/几何实现、最终布局和视觉返修记录。上述数值均为这些版本里的实例或清楚标明的字段示意；没有把未验证的参考片软件、插件和原作者参数当作事实。
